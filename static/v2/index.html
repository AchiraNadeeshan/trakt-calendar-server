📅 Trakt Calendar Server

Generate an iCal calendar from your Trakt.tv shows and movies. This allows you to subscribe to your Trakt activity in calendar apps like Google Calendar, Apple Calendar, or Outlook.

API Usage (v2)

Just open: This Link


And log into Trakt.
If the OAuth workflow succeeded, you'll get a link in this form:
https://$HOST_NAME/api/v2/ical?user_id=[id]&secret=[secret]

Use this URL to subscribe in your calendar app.
Google Calendar: Settings → Add Calendar → From URL
